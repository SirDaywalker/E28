# BMW E28 Showcase Website

Dieses Projekt entstand im Rahmen des Moduls *Webdesign und Webstandards II* an der Berufsakademie Rhein-Main.

Die Aufgabe bestand darin, eine vollständig statische Website zu konzipieren, zu gestalten und anschließend ausschließlich mit HTML und CSS umzusetzen. Das Projekt verbindet zwei persönliche Interessen von mir: die Webentwicklung und Oldtimer.

Der BMW E28 wurde bewusst als Thema gewählt, da er als Fahrzeug eine besondere Kombination aus Technik, Design und Charakter verkörpert. Ziel war es, diese Eigenschaften in Form einer modernen und visuell ansprechenden Website zu präsentieren.

---

## Projektübersicht

Im Rahmen des Moduls wurde ein umfangreicher Onepager rund um den BMW E28 entwickelt.

Von der ersten Idee bis zur fertigen Website wurden alle Schritte eigenständig umgesetzt:

- Konzeption und Strukturierung der Inhalte
- Erstellung eines vollständigen UI-Designs
- Umsetzung mit HTML und CSS
- Optimierung für verschiedene Bildschirmgrößen
- Einhaltung aktueller Webstandards

Der Fokus lag dabei nicht nur auf der technischen Umsetzung, sondern auch darauf, ein stimmiges Nutzererlebnis zu schaffen.
